# MSG-617: [모바일] 뱃지 획득 모달 — 업로드 확정 응답 `newBadges`로 획득 즉시 축하 모달 표시

> **보류(2026-10-03, 사용자)** — 수정사항을 더 모은 뒤 구현. 네이티브 변경 없음이라 1.0.2 묶음(MSG-616)과 독립, 착수는 사용자 재지시 시. Q1(`newBadges` 실채움 여부)은 미답.

## 기획 요약

업로드 확정(일반·행사 — 모바일에 존재하는 확정 경로 2종) 응답의 `newBadges`가 1개 이상이면 업로드 완료 오버레이(`upload-complete-view`) 위에 축하 모달을 띄운다. 모달은 "새 뱃지 획득" 헤드라인·메달 아트(도감과 같은 `resolveBadgeArt` 규칙)·이름·설명(null이면 생략)을 보이고, 여러 개면 점 인디케이터로 한 장씩 넘긴다([다음]→마지막 장 [확인]). 버튼은 **주 버튼 1개**([확인]/[다음], 전체 폭)뿐이고, [확인]·딤·하드웨어 뒤로가기는 모달만 닫는다. **도감 이동 버튼은 두지 않는다**(2026-10-03 사용자 결정 — 도감에 가도 볼 별도 컨텐츠가 없음). 1회만 뜨고(재시작·이어가기 재노출 없음), 완료 화면의 알림 권한 프롬프트와 겹치지 않는다. 웹·서버·뱃지 아트·도감 뱃지 탭 본문은 무수정.
