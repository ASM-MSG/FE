## 리스크
- R1 `submitConsents`가 위치 동의 컬럼을 건드리는지 불명 → 두 요청을 순차로 보낸다(서버 구현 확인: consents는 marketing+시각만 기록).
- R2 내 영상 판정을 닉네임으로 함(getMe에 userId 없음) — 닉네임 유일 전제.
- R3 `grid-detail` 삭제로 nose 가족 변동 — 삭제 파일 가족 drop.
