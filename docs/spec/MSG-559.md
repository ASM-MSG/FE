## 기획 요약

MSG-556이 만든 앱 `/ai-route` 화면(문장 + 현재 뷰포트 → `POST /api/routes/recommend` 1회 → 카드 + 오버레이) 위에 웹 MSG-489의 자동 동작을 얹는다. ① 제출 시 현위치가 뷰포트 안이면 `origin`을 실어 보내고 입력 카드에 "현재 위치에서 출발"을 표시한다(권한 거부·미확보·뷰포트 밖이면 조용히 생략). ② 제출은 **항상 1km 축척**(`MAP_SCALE_1KM_ZOOM`=13)으로 정규화한 뒤 나간다 — 아니면 줌을 먼저 맞추고 새 뷰포트가 반영된 뒤 보낸다(클릭 즉시 로딩). ③ 1차 응답에 `mentionedArea`가 실리면 확인 없이 그 중심으로 이동 + 1km 고정 + 토스트 3초 + **새 뷰포트로 2차 자동 재요청 1회**(1차 결과는 게시하지 않고 로딩 유지, 서버 10초 창 대기). 두 대기(정규화·2차)는 3초 상한으로 반드시 종결하되 **앱이 백그라운드인 동안은 마감을 세지 않고**(AppState), 어떤 경로로도 서버 상한(한 변 0.5°)을 넘는 뷰포트는 보내지 않는다. 결과가 온 뒤에는 재정규화·재요청이 없어 자유롭게 확대할 수 있다. 서버 API 변경 없음.
