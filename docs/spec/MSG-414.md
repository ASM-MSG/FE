# MSG-414: 도감 업로드 잔디 연동

## 기획 요약

개인 도감에 날짜별 업로드 기록(잔디) 섹션을 추가한다 — `GET /api/collections/upload-history`(KST 날짜 라벨, 인증 필수) 연동. 도감에 **기록 탭을 신설**해 최근 24주 잔디를 보여주고, "전체 보기"로 **1년(53주) 잔디 모달**(GitHub 기여그래프 구조 + 브랜드 5단계 램프)을 연다. 잔디가 세는 대상은 날짜별 업로드 수 — 도감 상단 "연속 스트릭" 지표의 확장이다. 미연동 API 해소 시리즈(MSG-407~415)의 마지막 티켓.

디자인 정본(Figma ver 13 통합 캔버스, 섹션 14783:3343 "🧱 미착수 티켓 시안 보강"):
- **기록 탭(24주 잔디)**: 프레임 `14783:3414` "MSG-414 개인 도감 — 기록 탭 (업로드 잔디)" (패널: 14783:3425, 잔디 카드: 14786:3572, 범례: 14786:3785)
- **기록 전체 보기(1년 잔디)**: 프레임 `14783:3808` "MSG-414 개인 도감 — 기록 전체 보기 (1년 잔디)" (모달: 14789:3824, 연간 잔디 카드: 14789:3834)

## API·코드베이스 대조 (스펙 전제 — 실재 확인 완료)

- **생성 SDK 실재**: `getUploadHistory` — `GET /api/collections/upload-history` (`sdk.gen.ts:831`), `getUploadHistoryOptions`/`getUploadHistoryQueryKey` (`react-query.gen.ts:1459~`). **파라미터 없음**(query/path/body 전부 never) — 기간 지정 불가, 전체 이력 일괄 응답.
- **응답** `UploadHistoryResponseDto[]`: `{ uploadDate: string /* 업로드가 있었던 KST 날짜 */, uploadCount: number /* 1 이상 */ }` — **희소 목록**(업로드 없는 날은 항목 자체가 없다). 봉투(`ApiResponseDtoList...`) 언랩 필요.
- **이 API는 현재 미사용** — 도감 상단 "연속 스트릭" 카드와 프로필 "내 활동"은 `collections/summary.currentStreak`을 쓴다(MSG-395). 재사용할 기존 쿼리 훅·키 없음 → 신규 훅이 첫 사용처다.
- **도감 탭 구조** (MSG-328·413·415 최신): 탭은 URL 정본 `/dex/:tab?` — `features/dex/model/dex-tab.ts`의 `DEX_TABS = ["map", "badges"]`가 소유(무효 파라미터는 지도 폴백). `DexTabs`는 DEX_TABS를 순회 렌더하므로 배열 확장만으로 pill이 늘어난다. `DexPanel`은 `tab === "map" ? (갤러리/동 목록) : (뱃지 게이트→BadgeTabBody)` 이분 분기 — 삼분기로 확장 필요. MSG-413(뱃지 편집모드)·415(더보기 메뉴)는 기록 탭과 파일이 겹치지 않는다(BadgeTabBody·VideoMoreMenu는 무변경).
- **도감 쿼리 관례**: 무파라미터 도감 조회 훅 3종이 `use-collection-query.ts`에 동거(envelope 언랩 select + `entityQueryPolicy`), 인증 게이트는 라우트 `RequireAuth`가 담당. 탭별 데이터 게이트는 뱃지 탭 패턴(에러→재시도 / 미도착→DotsLoader / 도착→본문)이 정본.
- **무효화 접점**: 업로드 확정(`useConfirmUpload`)·교체(`useReplaceVideo`)는 region-videos+격자 계열, 삭제(`useDeleteVideo`)는 `getSummaryQueryKey`(스트릭 카드)까지 무효화 중 — 잔디 키 추가 지점이 이미 존재한다.
- **모달 셸**: ui-web `DialogShell`(Radix — 포커스 트랩·Esc·스크림 닫기)이 관례이나 `max-w-120`(480px) 고정 — 1년 잔디 모달(시안 960px)에는 폭 옵션 확장이 필요하다.
- **토큰 대조**: 시안 램프 실측 lv0 `#EDEFF2` · lv1 `#C7DFF7` · lv2 `#8CBBEF` · lv3 `#4A93E0` · lv4 `#0066CC`. **lv4는 `primary`(blue-500)와 정확히 일치**, lv0~3은 현 토큰에 없음(투명도 근사도 실측과 불일치) → 선등록 필요(theme-*·red-600 선례, 추정 A4).
- Figma 변수 바인딩 없음(`get_variable_defs` 빈 결과) — 시안은 raw hex, 코드는 토큰 매핑이 정본.

## Figma 시안 판독 (스크린샷 확인 완료)

- **기록 탭**: 탭 pill 지도·뱃지·**기록**(활성) → 섹션 헤더 "업로드 기록" + 우측 "전체 보기 ›"(primary 텍스트 링크) → 메타 라인 "최근 24주 · 48일 업로드 · 최장 연속 12일" → 잔디 카드(340×153, surface-soft 계열 배경·라운드): 상단 월 라벨(3월~8월), 좌측 요일 라벨 **월/수/금**(행 1·3·5 → 행 0 = 일요일, GitHub 구조), 24열×7행 격자(9px 셀·3px 간격·radius 2), 우하단 범례 "적음 [5단 스와치] 많음".
- **전체 보기 모달**: 중앙 모달 960×352 — 헤더(제목 "업로드 기록" + 우측 "최근 1년 ▾" pill + ✕) → 헤드라인 "지난 1년 동안 128일 업로드했어요" + 부제 "최장 연속 12일 · 하루 최다 4개 · 가장 활발한 요일 토요일" → 연간 잔디 카드(월 라벨 9월~8월, 요일 라벨 월/수/금, 53열×7행, 12px 셀·4px 간격) + 우하단 범례. 배경은 도감 패널이 열린 지도 위 딤 오버레이.

- **A3. 레벨 임계 고정: 0 / 1 / 2 / 3 / 4+** — 시안 부제 "하루 최다 4개"와 일 업로드 수가 작은 도메인 특성상 고정 임계가 직관적. 대안: GitHub식 상대 분위(최대값 기준 4등분) — 이력이 적을 때 과포화되는 단점이 있어 기각 제안.
- **A4. lv0~3 색은 design-tokens 선등록(실측 hex)** — `#EDEFF2`·`#C7DFF7`·`#8CBBEF`·`#4A93E0` 4종을 원시 토큰으로 등록(명명 예: `grass-0`~`grass-3`, lv4는 `primary` 매핑). `bg-primary/25` 류 투명도 근사는 실측과 불일치 + "근사 사용 금지" 선례(theme-*)와 충돌이라 기각 제안. Figma 변수 등록은 백엔드/디자인 환류 후보로 기록.
- **A5. "최근 1년 ▾" 셀렉터는 정적 라벨로 구현(캐럿 제거)** — API가 기간 파라미터를 받지 않아 연도 전환 데이터가 없다. 동작 없는 드롭다운 시늉(캐럿)은 기만적이라 캐럿 없는 정적 pill "최근 1년"만 표시 제안. 캐럿 유지(비활성)나 항목 1개짜리 실셀렉터를 원하면 지정 필요.
- **A6. 모달 폭은 DialogShell 비파괴 확장으로 수용** — 기본값(max-w-120) 유지 + 옵션 prop. 로컬 Radix 재조립(관례 이탈)은 기각 제안.
- **A7. 빈 이력 상태 = 전부 lv0 잔디 + "0일 업로드" 메타** — 시안에 빈 상태 프레임이 없다. 격자 자체를 항상 렌더(잔디의 "비어 있음"이 곧 상태 전달)하고 별도 빈 상태 문구·일러스트는 두지 않는 제안. 첫 사용자 안내 문구를 원하면 지정 필요.
- **A8. 무효화 3지점(확정·교체·삭제) 추가** — upload·video-actions 파일 3곳 소폭 수정이 범위에 들어온다. `staleTime 5초`라 무효화 없이도 재관찰 시 대개 갱신되지만, 스트릭 카드(summary)와 잔디가 어긋나는 창을 없애는 값싼 정합 조치라 포함 제안. 범위 축소(무효화 생략) 선호 시 지정 필요.

## 리스크

- **삭제·교체의 서버 이력 의미 미상**: 영상 삭제/교체가 과거 `uploadDate` 집계를 감소·이동시키는지 OpenAPI에 기술 없음. FE는 무효화(A8)로 재조회만 보장 — 서버가 이력을 보정하지 않으면 잔디도 그대로다(백엔드 환류 후보, FE 결함 아님).
- **전량 응답 스케일**: 파라미터 없는 전체 이력 응답이라 수년 사용 시 항목이 늘 수 있으나, 일 단위 집계(연 최대 365행)라 실질 위험 낮음 — FE는 창(24주/53주) 밖 데이터를 파생 단계에서 버린다.
- **타임존**: `uploadDate`는 KST 라벨 — 브라우저 로컬 TZ가 KST가 아니면 `Date` 파싱·"오늘" 계산이 하루 어긋날 수 있다. 순수 함수는 날짜 문자열 산술 + KST 고정 "오늘" 주입으로 설계(수용 기준 4), 테스트에 TZ 경계 케이스 포함.
- **상단 "연속 스트릭" 카드와 값 상이 가능**: 카드는 `summary.currentStreak`(현재 진행 중 연속), 잔디 메타는 창 내 **최장** 연속 — 서로 다른 지표가 정상이다(시안이 둘 다 12일인 것은 플레이스홀더 우연). 검증에서 불일치를 결함으로 오판하지 말 것.
- **DexPanel 동시 수정 이력**: MSG-413·415가 방금 pages/dex를 변경 — 둘 다 develop 머지 완료라 병렬 충돌은 없으나, DexPanel 분기 확장 시 뱃지 게이트(413의 props 전달)·미니 패널 배선을 회귀시키지 않아야 한다(기존 도감 스모크 21케이스가 게이트).
- **Figma 오탐 방지** (page-verifier 대조 기준):
  - 시안 수치는 전부 플레이스홀더 — "48일 업로드·최장 연속 12일"(탭), "128일·최다 4개·토요일"(모달), 프로필 "필맵퍼·0.012%·부산진구 52%·6/4/12일". 실데이터 파생 렌더가 정본, 하드코딩 금지.
  - 지도 배경(에리카 캠퍼스·예체능대학 — 서면 아님)과 잔디 분포 패턴은 디자인 임시값.
  - 시안 월 라벨은 24주를 6개월로 **균등 배치**(4주 간격 고정) — 구현은 실제 월 경계 기준 배치라 라벨 위치·개수가 다를 수 있다(결함 아님).
  - "최근 1년 ▾" 캐럿은 구현에서 제거(A5 — 동작 없는 셀렉터 시늉 배제). 시안과의 의도적 차이.
  - 잔디 셀 색은 시안 raw hex가 아닌 등록 토큰 경유(A4) — 동일 값이므로 시각 차이는 없어야 한다(lv4=primary=#0066CC 실측 일치 확인 완료).
  - 시안 탭 프레임의 기록 pill 폭(48px)·탭 3개 배치는 기존 DexTabs 스타일(min-w-10·px-3) 승계로 미세 차이 허용.
