# MSG-407: 위치정보 동의 온보딩 게이트 연동

> 2026-08-17 사용자 승인 완료 — 질문 4건 답변 확정 반영 (v2). 확정 내용은 "확정 사항" 절 참조.

## 기획 요약

서버 게이트(MSG-402)가 이미 배포돼 신규·기존 계정 모두 `locationConsent=false`인 상태다. 로그인된 사용자의 `GET /api/users/me` 응답이 `locationConsent=false`면 앱 대신 전면 동의 화면을 띄우고, "동의하고 시작하기"가 `PUT /api/users/me/location-consent {"consented": true}`를 호출해 게이트를 연다. 함께: 프로필 편집의 위치 동의 토글을 실연동하고 프로필 패널의 "위치정보 동의 관리" 행을 활성화("준비 중" 해제)하며, 프로필 이미지 삭제(`DELETE /api/users/me/profile-image` — [기본 이미지로])를 추가한다. 브라우저 위치 권한 팝업은 이 화면에서 띄우지 않는다(동의와 권한은 별개 층 — 권한은 지도 홈 첫 사용 시).
