# MSG-407: 위치정보 동의 온보딩 게이트 연동

> **v3** (2026-08-17) — 사용자 후속 결정 2건 반영: ① 프로필의 위치 동의 토글 전면 제거(v2 확정 3 번복 — v2 기준 12~15 폐기), ② 게이트 전면 차단 유지 확정(뒤로가기 탈출 불가 = 의도된 설계). v2(2026-08-17): 질문 4건 답변 확정.

## 기획 요약

서버 게이트(MSG-402)가 이미 배포돼 신규·기존 계정 모두 `locationConsent=false`인 상태다. 로그인된 사용자의 `GET /api/users/me` 응답이 `locationConsent=false`면 앱 대신 전면 동의 화면을 띄우고, "동의하고 시작하기"가 `PUT /api/users/me/location-consent {"consented": true}`를 호출해 게이트를 연다. 함께 프로필 이미지 삭제(`DELETE /api/users/me/profile-image` — [기본 이미지로])를 추가한다. **프로필 쪽 위치 동의 접점(편집 모달 토글·설정 행)은 결정 1로 전면 제거** — 동의는 온보딩 게이트에서만 이뤄지고 인앱 철회 수단은 이번 티켓에 없다(리스크 절 참조). 브라우저 위치 권한 팝업은 이 화면에서 띄우지 않는다(동의와 권한은 별개 층 — 권한은 지도 홈 첫 사용 시).
