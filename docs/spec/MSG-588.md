# MSG-588: [모바일] 로그인 화면 로고를 새 심볼로 교체 + 저해상 해소

## 기획 요약
`login-screen.tsx`가 `fillmap-app-icon.png`(104×104, 구 앱 아이콘 디자인)를 `size-26`(104dp)로 렌더 → 3x 기기에서 3배 업스케일로 뭉개짐. 새 브랜드 심볼(격자+핀)로 교체하고 4x 해상도로 넣는다. 사용자 요청 2026-09-10 ("로고를 바꿔야해. 중앙에 뜨는거 해상도 괜찮게"). 실행 모드: 경량(로직 변경 0 — 에셋 + Image prop).

## 코드베이스 현황
- 소비자: `apps/mobile/src/features/auth/ui/login-screen.tsx` 1곳 (자산 `features/auth/assets/fillmap-app-icon.png`)
- 온보딩(`features/onboarding/ui/*`): 이미지·로고 요소 없음 — Figma 온보딩 v2 골격에 로고 자리 없음 → 범위 밖 확인
- 웹은 MSG-464에서 416px 알파로 이미 처리(디자인은 구 아이콘) — 웹 무수정
- 자산 선택: 팩 12종 중 `symbol-color`(투명 배경·컬러) — `app-icon-*`는 배경 사각형이 halo 위에 그대로 보여 부적합, `logo-full/horizontal`은 워드마크 포함이라 태그라인과 중복

## 구현 계획
- `fillmap-app-icon.png` → `fillmap-symbol.png`(356×416, `print-2x/symbol-color@2x.png` 투명 여백 trim 후 LANCZOS 축소, 99KB)로 교체·개명
