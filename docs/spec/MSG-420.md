# MSG-420: [모바일] ui-native 공통 컴포넌트 보강 + 바텀 내비 친구 탭 교체

## 기획 요약

Figma "필맵 앱 디자인 MVP ver 6" 페이지(14799:25586)의 모바일 개편 디자인에서 반복 사용되는 공통 컴포넌트 6종(VideoCard·CellBadge·Checkbox·SegmentedProgress·StatTile·ActionSheet)을 `packages/ui-native`에 추가한다. ActionSheet는 2026-08-06 합의(두 번째 사용처 등장 시 more-menu-sheet 승격)의 이행이다. 바텀 내비 2번째 탭을 탐색 → 친구(라벨·사람 2인 아이콘)로 교체하되, 친구 기능은 기획 미정이라 "준비 중" 스텁까지만 만든다. 이후 화면 티켓들이 이 컴포넌트를 소비하며, `packages/ui-native/src/index.ts`는 이 티켓이 독점한다.

## 코드베이스 대조 결과 (스펙 근거)

- ui-native 현황: 18종 + `cx` export (`packages/ui-native/src/index.ts`) — 티켓 [참고] 목록과 일치. 전 컴포넌트 스토리 보유.
- RN Storybook: `apps/mobile/.rnstorybook/main.ts`가 `packages/ui-native/src/**/*.stories.@(ts|tsx)` glob 자동 등록 — 신설 스토리는 파일 추가만으로 등록됨(`storybook.requires.ts` 수정 불요). 실행: `apps/mobile`에서 `EXPO_PUBLIC_STORYBOOK=1 expo start --dev-client`.
- `apps/mobile/src/app/_layout.tsx`는 generic `<Stack>` 1개 — expo-router 파일 기반이라 라우트 추가/삭제에 _layout 수정 불필요(수정 금지 제약과 충돌 없음).
- 바텀 내비: ui-native `BottomNav`(items 주입식) + `apps/mobile/src/widgets/bottom-nav/app-bottom-nav.tsx`(TAB_META: 홈·탐색·도감·프로필, lucide `Compass`=탐색) + `widgets/tab-stub/tab-stub-screen.tsx`(화면명 텍스트 스텁) + `app/explore.tsx`(탐색 스텁 라우트).
- 승격 원본: `apps/mobile/src/features/grid-detail/ui/more-menu-sheet.tsx` — RN Modal 딤(bg-navy-900/40) + ui-native BottomSheet 쉘 + MenuRow(아이콘+라벨, danger red-600) + 취소 border pill + 홈 인디케이터 인셋.
- 웹 참고(복사 금지): `apps/web/src/pages/map-home/ui/FeedVideoCard.tsx`, `packages/ui-web/src/cell-badge.tsx`(label+className, `rounded-sm bg-primary px-sm py-1.25 text-fm-body-strong text-primary-foreground shadow-raised`).
- 기존 앱 로컬 유사물: `features/map-home/ui/grid-video-card.tsx`(격자 카드 — 2줄 메타)·`theme-video-card.tsx`(테마 카드 — 1줄 메타). 도메인 결합으로 features에 존치된 것들 — 이번 티켓의 VideoCard는 도메인 무관 공통형.
- `design-tokens/src/variants.ts`에 신규 6종 관련 공용 타입 없음. ui-web에 Checkbox·SegmentedProgress·StatTile·ActionSheet·VideoCard 대응 없음 → 로컬 타입 정의(Thumbnail의 `ThumbnailShape` 선례). CellBadge만 웹 대응 존재 — 동일 props API(label·className) 미러.
- `tailwind-preset/native.ts` 보충 스케일에 `0.75`(=3px) 이미 존재 — SegmentedProgress 바 높이 `h-0.75` 사용 가능.

## 승인 시 결정 (2026-08-18, 사용자 승인)

- **[결정 1 — 질문 1 해소] ProgressBar를 7번째 신설 컴포넌트로 추가한다.**
  근거: 후속 티켓 12개(MSG-419·421~431) description 전수 조회 결과, **연속형 진행바** 수요가 3곳 확인됐다 — MSG-424(업로드 분석 중 진행 바), MSG-425(도감 탐험률 진행 바), MSG-430(기록 탭 요약). SegmentedProgress는 n분할 전용이라 커버 불가하고 ui-web에도 대응이 없다. index.ts를 이 티켓이 독점하므로 지금 넣지 않으면 후속 티켓이 규칙을 어기거나 이 브랜치로 환류해야 한다.
  구현: `progress-bar.tsx` — props `value`(0~1 또는 percent)·`className`. 트랙(회색 토큰) + 채움(primary) 2뷰, 높이는 토큰 스케일. 스토리 동반. index.ts export 포함.
  그 외 후속 요구는 기존 18종 + 신설 6종으로 충족 확인: 도감 3탭 → `Selector`, 프로필 알림 토글 → `Switch`, MSG-431 삭제 확인 다이얼로그 → `ModalCard`, 배지류 → `Chip`/`CellBadge`. MSG-430 뱃지 메달 아트·잔디 히트맵은 명시적 범위 밖.
- **[결정 2 — 질문 2 해소] `app/explore.tsx`를 삭제한다.**
  근거: `/explore` 참조는 `widgets/bottom-nav/app-bottom-nav.tsx`의 TAB_ROUTES와 `app/explore.tsx` 자기 자신뿐(전수 grep 확인). 나머지 "explore" 문자열 히트는 웹 모듈 출처를 적은 주석·테스트 설명뿐으로 라우트와 무관하다. 병렬 티켓 MSG-419는 `app/_layout.tsx`만 소유해 충돌 없음.
- **[결정 3 — 질문 3 해소]** 친구 스텁 "준비 중" 카피는 지정 없음 → builder 재량. TabStubScreen에 보조 문구 옵션을 추가하는 추정 4를 그대로 채택.

### 검증 결과

수용 기준 14개 **전부 통과 — 실패 0 · 확인불가 0**. 자동 게이트 6종(web 174파일/1176테스트 · mobile 40파일/187테스트 · typecheck 6프로젝트 · oxlint 위반 0 · format 690파일 · 중복 검사 · openapi 드리프트)을 검증자가 루트에서 직접 재실행해 빌드 리포트 실측값이 재현됐다.

**실기동 대체 확증** — `expo-dev-client`가 양쪽 레포 node_modules에 없고 Xcode·prebuild가 부재해 앱 실기동이 불가했다. 확인불가로 두지 않고 Metro 실번들로 대체 확증: Storybook 번들(HTTP 200/22.4MB)에 신설 7종 스토리 타이틀 전부 등재, 앱 번들(HTTP 200/17.5MB)에서 `TAB_META`·`TAB_ROUTES`·`friends.tsx` 컴파일 결과 직접 추출, NativeWind CSS 실빌드로 `size-6.5`·`py-1.25`·`h-0.75` 생성 실측.

**번들 포트 함정이 실제로 발생했다** — 포트 8081을 메인 레포(`~/fillmap/FE`)의 Expo가 점유 중이었고 `adb reverse`도 그쪽이었다. 딥링크로 이 워크트리를 지정해도 콜드 스타트가 8081로 복귀해 **구 코드(탐색 탭)를 렌더**했다. 판정 근거에서 배제하고 검증 후 `adb reverse`를 원복했다. (병렬 워크트리 검증의 상시 함정 — 번들 출처 교차 확증 없이는 오판한다.)
