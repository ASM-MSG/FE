# MSG-328: 지역 탐색·검색 API 연동

## 기획 요약

탐색 페이지(`/explore`)가 홈과 역할이 겹쳐 제거하고, 지역 탐색·장소 검색을 홈 좌측 패널로 통합한다. 홈 좌측 패널을 Figma 14357-18972 기준으로 리디자인한다 — 상단 검색바 + 현재 지도 중심 행정동 헤더("전체 보기" 포함) + 격자 카드 세로 리스트 + 지도 이동 시 "{행정동} 장소 불러오기" 재검색 버튼. 지역 API 3종(`reverse-geocode`·`{regionCode}/grids`·`explore`)과 검색 API 2종(`places`·`trending`)을 실 연동한다.

**사용자 기확정 해석** (재질문 불필요): 현재 행정동 판별 = 지도 중심 좌표의 reverse-geocode(GPS 아님) · "장소 불러오기" 버튼 = 지도 이동 시 노출되는 재검색 패턴 · "전체 보기" = 패널 안에서 전체 지역 리스트 열림.

| 9 | "장소 불러오기" 클릭 시 헤더·격자 리스트가 새 행정동 기준으로 갱신되고 버튼이 사라진다 | 화면 | 브라우저 |

| 11 | 격자 리스트·지역 리스트 각각 로딩·빈 결과("이 지역에는 아직 격자가 없어요" 류)·요청 실패(재시도 버튼) 상태를 처리한다 | 화면 | 브라우저(스텁/네트워크 차단) |

## 리스크

- **비로그인 홈 접근**: 5개 엔드포인트 모두 스펙상 bearer 보안 표기. 홈은 비로그인 접근 가능 페이지 — 익명 요청이 401이면 패널·검색이 전부 실패 상태로 뜬다. **사용자 확정(2026-08-13): 구현 중 익명 호출을 실서버로 실측해 위임 판단** — 익명 허용이면 그대로, 401이면 로그인 유도 UI로 처리하고 근거를 작업 로그에 기록
