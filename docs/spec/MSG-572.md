# MSG-572: [모바일] 업로드 미리보기 공개 범위 선택(전체 공개·나만 보기) + 확정 body visibility 전송 (웹 MSG-476 ① 이식)

## 기획 요약

앱 업로드 미리보기(`features/upload/ui/preview-screen.tsx`)에 웹 MSG-476 ①과 같은 "공개 범위" 카드(전체 공개 / 나만 보기, 기본 전체 공개)를 붙이고, 일반 확정 `POST /api/videos` body에 `visibility`를 PUBLIC 포함 **명시 전송**한다. 선택은 이전 단계 왕복·콜드 스타트 복원에도 유지되고, 완료 [확인](`reset`) 뒤 다음 업로드는 전체 공개로 돌아간다. 행사 귀속 업로드(`eventTarget !== null`)는 DTO에 필드가 없어 카드 미노출·미전송. 웹·packages·서버 계약 무수정.

## 코드 실측 (스펙 근거, 2026-09-04)

- **DTO**: 모바일 `shared/api/sdk.ts`는 웹 `apps/web/src/shared/api/generated`를 재수출한다. `VideoUploadRequestDto.visibility?: string`("PUBLIC, PRIVATE, FRIENDS 중 하나. 생략 시 PUBLIC", types.gen.ts:303-306) — **스냅샷에 이미 있어 `api:generate` 불필요**. `EventVideoUploadRequestDto`는 `s3Key·durationSec·recordedAt`뿐(1134-1147) — 행사 모드는 보낼 수 없다.
