# MSG-565: [모바일] 지도 홈 현재 위치 표시 — 파란 점·정확도 원·내 위치 버튼 활성 상태

> 원문: `_workspace/MSG-565/00_ticket.md` (2026-09-04 MCP 조회). 부모 에픽 MSG-291. 모바일 티켓 — `apps/web`·`packages/ui-web` 0줄.

## 기획 요약

앱 지도 홈은 내 위치 버튼으로 카메라만 옮기고 지도 위에 내 위치를 그리지 않는다(MSG-559가 "현재 위치 점"을 제외). 홈에 현재 위치를 파란 점(흰 링·그림자) + 측위 정확도 반투명 원으로 상시 표시하고, 위치 갱신을 홈이 활성일 때만 구독하며, 내 위치 버튼에 "추적 중"(아이콘 primary) 상태를 준다. 드래그하면 추적이 풀린다. 권한 거부·측위 실패는 점·원 없이 기존 MSG-447 안내 흐름 그대로다.

- **A2 내 위치 탭 줌**: [동작 요구] 4의 "줌 유지"를 따라 `panTo`(줌 불변). 종전 `moveTo`는 줌 16으로 되돌렸으므로 홈 동작이 바뀐다(저줌 클러스터 상태에서 탭하면 줌 그대로 중심만 이동). AI 추천 화면의 `handleLocate`는 손대지 않는다
- **A3 정확도 원 스타일**: `primary` 20% 채움, 테두리 없음. Figma glow(40%+blur)는 평면 원으로 옮기면 지도 가독성을 해쳐 낮췄다 — 실측 근거 없는 값이라 검증 스크린샷으로 확인 후 조정
- **A4 구독 옵션**: `Accuracy.Balanced`(expo 기본) · `timeInterval 3000ms` · `distanceInterval 5m`. 배터리·갱신 체감의 절충값, 티켓에 수치 없음
- **A5 정확도 상한 없음**: accuracy가 수 km(네트워크 측위)여도 그대로 그린다 — 사실 표시이고 캡은 YAGNI
- **A6 점 크기**: 30dp(Figma dot 그룹 그림자 포함 bounds 30×30). glow 64×64 박스는 쓰지 않는다
