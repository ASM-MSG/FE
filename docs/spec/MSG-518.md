# MSG-518: 행사방 상세 — 위치 선택 · 위치별 영상 목록 · 빈 행사 위치 상태

## 기획 요약

행사 웨이브(MSG-516~521)의 웨이브 2 티켓. MSG-516이 깔아 둔 행사방 패널 셸의 확장점(`EventRoomBodySwitch`·`event-room-mode`)에 **위치 선택 상태 + 위치별 영상 목록(videos) + 빈 위치 상태(empty)** 본문을 얹는다. 행사 위치가 선택되면 그 위치에 올라온 영상 목록(Figma 15518:6364)이 뜨고, 영상이 없으면 "첫 영상 올리기" CTA가 있는 빈 상태(15518:6612)가 뜬다 — CTA는 **렌더까지만**(업로드 연결은 MSG-521). 카드 클릭 재생·좋아요·댓글은 MSG-520, 아카이브는 MSG-519. MSG-517(위치 개요)·MSG-519(아카이브)와 **병렬 진행 중**이다.

**서버 계약 (develop에 이미 생성돼 있음 — `api:generate` 재실행 금지):**
- `getLocationVideos` — `GET /api/event-occurrences/{occurrenceId}/locations/{locationId}/videos`: 최신순 keyset 커서 페이지(size 기본 20, cursor는 직전 `nextCursor`), **익명 조회 허용**, 영상 없으면 실패가 아니라 빈 페이지. 항목 `EventLocationVideoResponseDto` = videoId·thumbnailUrl·durationSec·createdAt·**helpfulCount·commentCount** (제목·소유자·조회수 없음 → 기존 `FeedVideoCard` 재사용 불가, 전용 카드 필요)
- `EventLocationResponseDto`(위치 하나) = locationId·name·type(POPUP/EXPERIENCE_ZONE/PARADE/PHOTO_ZONE/ETC)·operatingHours·gridIds·representativeGridId·zoneName/zoneCell/regionName·videoCount 등 — 위치 헤더 블록의 재료. **위치 목록 조회(`getLocations`)는 MSG-517 소유(개요 위치 목록)** — 이 티켓은 선택 시점 스냅숏만 스토어에 담아 중복 쿼리 훅 생성을 피한다
- 서버 명시: "영역 안 어느 격자를 눌러 들어와도 같은 위치의 같은 피드다" — 격자별 영상 필터는 **서버에 존재하지 않는다** (리스크 참조)

## 추정 및 질문

**추정 (스펙에 반영, 승인 대상):**
1. **위치 선택 스냅숏 방식** — 이 티켓은 `getLocations` 쿼리를 만들지 않고(MSG-517 소유 회피) 선택 시점의 위치 DTO 스냅숏을 스토어에 담는다. 헤더의 "영상 N"은 이 스냅숏 `videoCount`라 업로드 직후엔 스테일일 수 있다(정합은 MSG-520/521에서 무효화로 해소).
2. **카드 비인터랙티브 렌더** — 클릭 동작이 없는데 button으로 만들면 아무 일도 안 하는 버튼이 낭독된다(a11y 결함). 이번엔 비버튼으로 렌더하고 MSG-520이 버튼화한다.
3. **헤더 "+ 영상 올리기" 버튼도 렌더만** — 티켓은 빈 상태 CTA만 명시했지만 Figma 정본(6364)에 있으므로 함께 렌더(no-op, MSG-521 확장점 주석).
4. **페이지네이션 UX** — Figma에 스크롤 끝 처리가 없어 `hasNext`면 "더 보기" 버튼으로 추정(무한 스크롤 아님).
5. **뒤로가기 2단** — 위치 선택 중 뒤로가기는 위치 해제(개요 복귀), 미선택이면 행사방 닫기. ESC도 같은 우선순위(기존 미니 패널 우선 닫기 체계에 위치 해제 층 추가).

**확정 결정 (2026-08-31 사용자 승인):**
1. **위치 선택 진입점의 배선 시점** — 확정: 이 티켓은 `selectLocation` API(+`toEventLocationSelection` 변환기)까지만 제공. 실제 클릭 배선은 517/518 중 나중에 머지되는 쪽이 잇는다. 단독 브라우저 검증은 스토어 직접 구동.

3. **행사방 헤더 타이틀** — 확정: 무변경 유지("이벤트" 고정). 행사명 표시는 517 또는 후속에서 조정.
