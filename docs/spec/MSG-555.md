# MSG-555: 콘솔 진입 링크 배선 — 로그인 모달 하단 · 칩 목록 패널 배너

## 기획 요약

일반 유저 앱에서 행사 운영자 콘솔의 존재를 발견할 유일한 경로인 진입점 3곳을 배선한다: ① LoginModal 하단 안내 링크 → `/org/login`, ② 지역축제·팝업스토어·경로추천 칩 활성 시 좌측 패널 최하단 안내, ③ 행사 목록 패널(지역축제/팝업스토어) 최하단 배너(Figma 15599:2492가 문구·스타일 정본). ②·③은 같은 컴포넌트를 재사용하고, 로그인 여부 무관 노출하며, 콘솔 lazy 청크 전제(프리로드 금지)와 기존 패널 레이아웃을 깨지 않는다.

## 코드베이스·Figma 대조 결과 (스펙의 전제 — 전부 실측)

- **②·③의 패널 대상은 칩 목록 패널로 수렴한다.** Figma 15599:2492의 노드명이 **"② 칩 목록 패널 388"**이고, 내부 구성이 칩 2개(지역축제 활성/팝업스토어) + 행사 카드 2장 + 최하단 배너(15599:2504 rect 348×66 + 텍스트 15599:2505·2506)다. 코드의 칩→패널 분기 정본은 `features/map-home/model/panel-branch.ts` — `festival`·`popup` 칩 = `MissionListPanel`(행사 목록, 칩이 곧 탭), `route` 칩 = `CourseListPanel`. 두 패널 모두 공용 껍데기 **`ChipListPanel`**(헤더 + 상태 4분기 + `overflow-y-auto` 본문)을 쓰고, ChipListPanel의 소비처는 이 둘뿐이다. 즉 ③ = MissionListPanel(축제·팝업 두 칩 상태), ② = 거기에 CourseListPanel 추가 — **배너 1개 컴포넌트를 ChipListPanel 계열 3표면에 얹으면 ②·③이 동시에 충족**된다. `EventRoomPanel`(행사방)·`HotRegionPanel`(핫구역)·`RegionPanel`·격자 상세는 대상이 아니다(티켓 칩 목록에 핫구역 없음 + 시안 노드명 근거).
- **①의 위치**: `features/auth/ui/LoginContent.tsx`(LoginModal의 단일 콘텐츠 소스 — 구성: 타이틀 → 로고 히어로 → 카카오 버튼 → 약관 문구 → DevLoginPanel(dev 전용)). 모달 열림은 전역 `login-modal-store` — 콘솔 이동 시 명시적으로 `closeModal()` 하지 않으면 스토어 open=true가 남아 유저 앱 복귀 시 모달이 다시 뜬다(콘솔 라우트는 AppLayout 형제라 언마운트만 될 뿐 상태는 잔존).
- **경로 상수**: `app/console-routes.ts`의 `CONSOLE_ROUTES.orgLogin = "/org/login"` — 문자열 상수뿐이라 유저 번들 무해(MSG-541 확정, 파일 주석 명시). features 레이어의 `@/app` 경로 상수 import는 `KakaoLoginButton`(`@/app/routes`의 `KAKAO_CALLBACK_PATH`) 선례가 있다.
- **lazy 전제**: 콘솔 코드는 route-level lazy 16개가 `app/console/console-bundle.ts` 단일 청크를 가리킨다(MSG-541 AC 3). react-router `Link`/`navigate`는 이동 시점에만 청크를 로드한다 — 배너·링크가 `app/console/`·`pages/org|admin`을 import하지 않는 한 전제가 유지된다.
- **ChipListPanel 상태 구조**: `isPending`이면 도트 로더만 early return(셸 자체 미렌더), 아니면 헤더 + `overflow-y-auto` div 안에 [부분 실패 notice → isError ? RetryNotice : count 0 ? empty 문구 : children] 순. "목록 끝 배너"는 이 스크롤 div 안 마지막 요소로 들어가야 티켓의 "목록이 길 때 목록 끝에 위치"(sticky 아님)가 성립한다.
- **브랜치**: MSG-555 브랜치는 로컬·리모트 모두 없음(신규 생성).
- 웨이브 3 병렬(548·553)과의 충돌면: 이 티켓의 터치 파일(features/auth ui·pages/map-home ui)은 위저드·admin 계열과 무접촉. `router.tsx`·`console-routes.ts`·`shared/api/generated/**` 수정 없음.

### 검토한 대안 (기각 이유 포함)

1. **ChipListPanel에 배너 내장 + `showConsoleBanner` 불리언 prop** → 기각. 껍데기가 노출 정책과 문구를 소유하게 되고, 문구·목적지가 바뀔 때마다 공용 껍데기를 다시 연다. 불리언 1개로는 표면별 차이를 담을 수 없다.
2. **각 패널이 ChipListPanel 바깥에 배너 렌더** → 기각. 스크롤 영역 밖으로 나가 AC 7("목록이 길면 스크롤해야 나타난다")을 정면으로 깬다.
3. **`#EDF7FF` 새 원시 토큰 선등록** → 기각. 차이는 RGB (5,2,0)·ΔE00 ≈ 0.9로 육안 식별 한계(JND ≈ 2) 아래고, 같은 "행사 연블루" 역할의 실측 기반 토큰(`event-tint`)이 이미 있다. "근사 사용 금지"는 투명도 근사(`primary/10` 류)를 막는 규칙이며, 근사-중복 연블루 원시 토큰이 2개가 되면 앞으로 어느 쪽을 쓸지 판단할 근거가 사라진다(디자인 시스템이 막으려는 바로 그 모호함).
4. **배너 높이 `h-16.5`(66px) 고정** → 기각. 문구가 줄바꿈되면 잘린다. Figma 고정 높이는 캔버스 표현이고 실제 패널 폭 388px에서 각 줄이 1줄이라 padding 기반이 안전.
5. **LoginModal이 라우트 변화를 관측해 닫기** → 기각. 콘솔 라우트가 AppLayout 형제라 언마운트만 되어 관측 지점이 없다.
6. **`useNavigate` + 핸들러에서 close 후 navigate** → 기각. `Link`가 주는 우클릭·새 탭·중간 클릭·href 노출을 잃는다(a11y 이름 단정도 `link` role 기반).
7. **`MissionListPanel`↔`CourseListPanel` nose 가족 추출** → 기각·베이스라인 등재. 불변 코어는 MSG-395가 이미 `ChipListPanel`로 뽑았고 남은 것은 nose 스스로 "high-parameter (9 varying spots)"로 경고하는 발산부다 — 카드 컴포넌트·문구 4종·`theme`·`progressLocked`를 전부 파라미터로 올리면 설정 객체 컴포넌트가 되고 MSG-395가 의도적으로 가른 두 도메인이 다시 붙는다. 테스트 픽스처 가족은 shared 0줄·removable 0줄이라 nose 권고대로 등재.
