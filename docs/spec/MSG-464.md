# MSG-464: 로그인 모달 로고 흰 배경·저해상도 + 영상 썸네일 깨진 이미지 폴백

## 기획 요약

프론트 QA 버그 2건. ① 로그인 모달 로고(`fillmap-app-icon.png`, 104×104)가 흰 바탕을 품은 원본이라 원형 회색 배경 위에 흰 사각형째 떠 보이고, 렌더 크기(104px CSS)와 원본 픽셀이 1:1이라 고해상도 화면에서 뭉개진다 — 투명 배경 고해상 자산으로 교체한다. ② 영상 썸네일은 `thumbnailUrl === null`이면 회색 폴백을 그리지만 **URL이 왔는데 로드에 실패한 경우의 `onError` 폴백이 어디에도 없어** 브라우저 깨진 이미지 아이콘이 노출된다 — null과 로드 에러 양쪽을 같은 자리에서 지정 기본 이미지(Figma 15231-353: 회색 배경 + 격자 로고 플레이스홀더)로 처리하고, 4개 렌더 지점의 중복을 ui-web 공용 컴포넌트로 승격한다.
