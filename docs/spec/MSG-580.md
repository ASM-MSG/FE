# MSG-580: [모바일] 경로추천 칩 목록 상태에서 지도에 코스 경로선·번호 마커 표시 (웹 parity)

> 원문: https://soma17-msg.atlassian.net/browse/MSG-580 (하네스 생성, 2026-09-07 — 사용자 QA "경로추천에서 지도에 경로가 표시가 안 된다")
> **수정 범위: `apps/mobile/src/features/map-home/` 5파일**(model 1 + 테스트 1 + ui 3). `apps/web`·`packages/**` 0줄.

## 기획 요약

경로추천 칩을 켜면 시트엔 코스 목록이 뜨는데 지도엔 포토스팟 격자 셀만 칠해지고 경로선·번호 마커가 없다. 코스를 탭해 상세로 들어가야 그 코스 하나만 그려진다. 웹은 칩을 켜는 즉시 목록의 모든 코스를 라인+번호 마커로 그리고 상세에서 그 코스만 남긴다.
