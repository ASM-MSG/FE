# MSG-557: [모바일] 행사방 1단계 — 지도 상단 행사 칩 · 행사 개요 · 행사 위치 표시 (웹 features/event 이식)

## 기획 요약

앱에 행사 개념이 없다(`apps/mobile` 소스에 `/api/event-occurrences` 참조 0건 실측). 웹 행사 웨이브(MSG-516~521·534·535) 중 **칩 → 개요 → 지도 위치 표시**까지만 앱으로 옮긴다. 동작·UX·표시값은 전부 웹 구현 코드(`apps/web/src/features/event` + `pages/map-home/ui/Event*`)를 정본으로 확정했고, 웹에 대응 동작이 없는 항목은 hey-api 생성물·서버 응답으로, 앱 고유 항목(칩 바 배치·시트·뒤로가기)만 이 스펙이 정한다. 서버·웹·`packages` 변경 0. 행사방 본체(시청자·하트비트·댓글·아카이브 본문·캡슐·위치별 영상·업로드)는 후속 티켓이며 확장점만 남긴다.
