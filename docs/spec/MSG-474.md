# MSG-474: 비로그인 지도 홈 개방 — 행정동 확정·장소 불러오기·칩 최근접 이동·해당 동 공개 영상 노출

## 기획 요약

QA 결함 3건(비로그인 최초 진입 시 로그인 안내만 뜸 · 지역축제 칩에서 "장소 불러오기" 미작동 · 칩 클릭 시 최근접 이동 안 됨)의 뿌리는 하나 — FE가 비로그인에서 역지오코딩을 게이트해 **확정 지역(commit)이 영영 생기지 않는 것**이다. 서버가 MSG-454(칩)·467(역지오코딩)·469(구역 목록·격자 요약·cover·videos)로 익명 조회를 열었고 2026-08-26 dev 실측 익명 200이 확인됐으므로, FE 게이트를 풀어 비로그인 기본 패널을 로그인 상태의 동 패널과 같은 구성(행정동 헤더 + 격자 카드 목록)으로 바꾼다. 사용자별 값(내 점령·내 영상 수·진행도·도감 집계)은 계속 미발사·미표시(MSG-463 `progressLocked` 선례)이며 401 스팸이 생기면 안 된다. 장소 검색·AI 경로추천 개방은 범위 밖.

**원인 추적 정정 (코드 실측)** — 티켓은 `use-nearest-entry`의 `center` null을 원인으로 적었으나, 그 훅의 `center`는 `viewportCenter`라 비로그인에서도 null이 아니다. 실제 사슬은: `useReverseGeocodeQuery(isAuthenticated ? … : null)` → `region` 항상 null → `use-chip-entry`의 확정(`commit`)이 `region === null`에서 무기한 대기 → `committedBounds`가 부트스트랩(`useCommittedRegionBootstrap`)이 영역만 선확정한 **최초 100m 뷰포트에 고정** → 칩 목록 bbox가 좁아 최근접 대상이 없거나(이동·소진 없음) 엉뚱하고, "장소 불러오기"는 `currentRegion`이 null이라 `deriveReloadTarget`이 버튼 자체를 만들지 않는다. 즉 역지오코딩 게이트 해제 한 가지로 3건이 함께 풀린다 — `use-nearest-entry`·`use-chip-entry`·`region-reload`는 무수정.

## 작업 로그 (2026-08-26)

### 실측이 스펙을 두 번 뒤집었다

착수 시 티켓은 "BE 선행 전부 배포 확인(익명 200)"이라고 적혀 있었으나 **오케스트레이터 익명 curl 1차 실측에서 `regions/{code}/grids`·`grids/{id}`·`videos/{id}`·`regions/explore`가 401**이었다 — 요구 2(동 카드 목록)·5(격자 상세)·재생이 전부 블로커였다. 사용자가 서버 권한을 다시 열고(`hey-api로 권한 200으로 다시 해놨어`) **2차 실측에서 `regions/{code}/grids` 200(부전2동 gridCount 37·videoCount 80)·`videos/{id}` 200(playbackUrl 발급)·`regions/explore` 200**을 확인해 요구 5건 전부 성립으로 확정했다. 교훈: 티켓의 "배포 확인" 문장을 그대로 신뢰하지 말고 착수 직후 익명 curl로 재확인한다 — 이 티켓은 그 한 단계가 범위를 두 번 바꿨다.
