## 기획 요약

MSG-557이 옮긴 칩 → 목록 → 개요 → 지도 채색의 **아래층**을 잇는다: 개요의 위치 행(현재 비인터랙티브)을 탭하면 위치 상세 시트(헤더·메타·격자 안내·"{앞토막} 현장 영상" 섹션·영상 카드·빈 상태·업로드 진입)가 열리고, 지도에서 그 위치 셀을 탭해도 같은 시트가 열리며, 열린 동안 그 위치 셀이 강조되고 라벨이 붙는다. 종료 이벤트는 같은 시트를 읽기 전용으로 보고, 개요 헤더에 시청 인원을 되살린다. 동작·표시값은 전부 웹 `apps/web/src/features/event` + `pages/map-home/ui/Event*` 코드와 hey-api 생성물·서버 실응답으로 확정했고, 웹에 없는 것(시트 스냅·셀 탭 진입·라벨 1개·업로드 플로우 사전 선택 방식)만 이 스펙이 정한다. 웹·`packages` 변경 0.
