# MSG-547: 위치 영역 지정 — 지도 격자 드래그 다중 사각형 · 81칸 합집합 상한 · 한 변 10칸 경고

## 기획 요약

등록 위저드 스텝 3(area). 좌측 패널 + 전면 지도 구성에서 지도 격자 위를 드래그해 격자 스냅 사각형을 여러 개 그리고, 합집합 81칸 상한 안에서 "이 위치의 영역" 목록으로 확정한다. 한 변 10칸 초과는 경고만 하고 확정을 허용한다(B안, 2026-09-01 확정 — 재논의 금지). "위치 저장"으로 areaRects가 위저드 스토어에 확정되고 검토 스텝(548 전까지 자리표시)으로 넘어간다. 영역 지정 로직은 지도 SDK와 분리된 순수 함수 + 테스트가 요구사항이다.

## 코드베이스 대조 결과 (스펙의 전제 — 전부 실측)

**서버 계약 (generated types 실측 — 재생성 금지)**
- `EventSubmissionAreaRectDto = {minGridY, maxGridY, minGridX, maxGridX}` — **`entities/cell/grid.ts`의 `GridRange`와 필드가 완전 동일**하다(우연 아님 — 둘 다 BE GridEncoder 정본). `EventSubmissionLocationRequestDto = {areaRects?}`(이름 필드 없음), `EventSubmissionCreateRequestDto.locations?: 1~20개`. 응답 쪽 `EventSubmissionLocationResponseDto.areaRects`는 "제출 원본 그대로 — 재제출 프리필 재료"(MSG-550 재료).
- 서버 판정은 합집합 81칸뿐 — 한 변 상한 판정 없음(티켓 명시와 일치).

**격자 정본 재사용 (entities/cell/grid.ts — 전부 순수·SDK 무관)**
- `cellIndexAt(latLng) → {gridX, gridY}`(드래그 좌표→셀), `gridNodeAt(index)`(셀 남서 교점 위경도 — 사각형 꼭짓점 역산), `cellCornersAt`, `viewportGridRange`. 새 좌표 산술을 만들 필요가 없다 — 조합만 한다.
