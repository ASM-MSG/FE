# MSG-425: [모바일] 도감 개편 1 — 3탭 셸·지도 탭 동 목록·동 갤러리 + 도감 API

## 기획 요약

모바일 개인 도감(`/dex`)을 mock 기반 2탭 화면에서 **실 API 기반 3탭 셸**로 전면 개편한다. 상단은 프로필 요약 대신 **탐험률 진행 바 + 통계 타일 3개**, 탭은 `[지도 | 뱃지 | 기록]`, 지도 탭 본문은 수집 격자를 **행정동(동) 단위로 묶은 최근순 목록(최대 20개)**, 동을 누르면 **격자별 섹션 + 1열 영상 카드** 갤러리로 전환된다. 웹 MSG-327(커밋 `0b702e5`)이 확립한 순수 파생 로직을 모바일로 포팅하고 parity 테스트로 고정한다. 뱃지·기록 탭 **내용**은 MSG-430, 영상 공개/삭제는 MSG-431 — 이 티켓은 그 둘이 얹힐 **셸과 공통 헤더를 소유**한다.

## API 계약표

모두 `apps/mobile/src/shared/api/query-options.ts`(웹 생성물 재수출)에서 import하고, `select: unwrapEnvelope`로 봉투를 벗긴다.

### 이 티켓이 쓰는 것 (5종)

| # | 엔드포인트 | 생성 옵션 | 요청 | 응답 `data` | 화면 용도 |
|---|---|---|---|---|---|
| 1 | `GET /api/collections/summary` | `getSummaryOptions()` | 없음 | `CollectionSummaryResponseDto` — `totalGridCount·totalVideoCount·visitedRegionCount·currentStreak·maxStreak·badgeCount` | 통계 타일 3개 (S2) |
| 2 | `GET /api/collections/grids` | `getCollectionGridsOptions()` | 없음 | `CollectionGridResponseDto[]` — `gridId("{gridY}_{gridX}")·gridY·gridX·firstCollectedAt·lastUploadedAt·videoCount·coverVideoId·coverThumbnailUrl·coverDurationSec·regionName(nullable)·zoneName(nullable)·zoneCell(nullable)` | 동 목록 원재료 (S4) |
| 3 | `GET /api/regions/stats/by-point` | `getStatByPointOptions({query:{lat,lng}})` | `lat`,`lng` | `RegionStatResponseDto \| null` — `regionCode·regionName·parentCode·collectedCount·totalCount·progressRate·updatedAt` | 탐험률 진행 바 (S1) |
| 4 | `GET /api/regions/stats/by-grid` | `getStatByGridOptions({query:{gridId}})` | `gridId` | `RegionStatResponseDto \| null` | 동→`regionCode` 조인 (S6·S12) |
| 5 | `GET /api/collections/videos` | `getRegionVideosOptions({query:{regionCode}})` | `regionCode` | `RegionVideoResponseDto[]` — `videoId·gridId·thumbnailUrl(nullable)·processingStatus·durationSec·createdAt·zoneName(nullable)·zoneCell(nullable)` | 갤러리 본문 (S7·S8) |

**조인 사슬 (웹 MSG-327 작업 로그 1번 — 이름 매칭 기각의 결론)**: `grids` 응답에 `regionCode`가 **없어서** 동을 코드로 지목할 수 없다. `deriveRecentRegions`가 만든 `sampleGridId`(그 동의 최신 격자)를 `by-grid`에 넘겨 `regionCode`를 얻고, 그 코드로 `collections/videos`를 조회한다. 동명이동 오매칭이 원리적으로 불가능한 경로다.

## "동 목록에서 X로 제거"의 의미 — **로컬 감춤 확정 (추정 아님)**

웹 선례에 명시적 근거가 있다. `apps/web/src/features/dex/model/recent-removal-store.ts` 주석:

> "최근 수집 목록 X 제거 상태 (AC 23, 개정 D4). **비영속(메모리, A11)** — 새로고침 시 목록이 복원된다. 제거는 서버 동기화 대상 상태로 보여 mock 단계에서 localStorage 영속을 도입하면 API 계약을 선점하게 된다. **수집 취소가 아니다** — 통계·오버레이 파생은 이 스토어를 참조하지 않는다(AC 24)."

그리고 `recent-regions.ts`의 `excludeRemovedRegions` 주석:

> "파생 **이후**에 적용한다 — 감춤은 표시 전용 상태이고 통계 카드·지도 표시는 이 결과를 입력받지 않는다(수집 취소가 아니다)."

MSG-327 수용 기준 8도 동일: *"행의 X 버튼으로 그 동을 목록에서 **감출** 수 있다(**비영속·수집 취소 아님**) — 통계 카드와 지도 표시는 불변"*. **서버 삭제 API를 호출하지 않는다**(OpenAPI에 대응 엔드포인트도 없다).

**모바일 구현**: 웹은 zustand 스토어(`recent-removal-store`)로 앱 세션 동안 유지하지만, **`apps/mobile`에는 zustand 의존성이 없다**(`package.json` 확인). 화면 로컬 `useState<string[]>`로 보관한다 → 감춤이 **도감 화면 언마운트 시 리셋**된다(웹은 탭 이동 후에도 유지). 수용 기준 S5는 "누르면 그 행만 사라진다"까지만 요구하므로 기준 충족에는 영향이 없다. **추정 A4** (zustand 도입 vs 화면 로컬).

## 리스크

- **명세 갭 — `CollectionGridResponseDto`에 `regionCode` 부재**: 동 클릭 시 `by-grid` 왕복 1회가 추가로 필요하다. 웹 MSG-327이 이미 백엔드 환류했고 우선순위 낮음으로 회신된 사안 — 모바일도 같은 우회를 쓴다(정확도 손실 없음).
- **명세 갭 — `RegionVideoResponseDto`에 `isNew` 부재**: FE 24시간 창(`isNewVideo`)으로 판정한다. 웹과 창 길이가 갈리면 같은 영상이 플랫폼별로 다르게 보이므로 parity 테스트가 방어한다.
- **`by-grid`가 `data: null`을 반환하는 경로**: 격자 중심이 행정동 밖·미판정이면 `regionCode`가 없어 영상 쿼리가 비활성이고, pending도 error도 아니다. 웹은 이걸 놓쳐 **영구 스켈레톤**에 갇혔다(codex 리뷰 [상] 지적). 모바일도 `regionUnresolved` 분기를 처음부터 넣는다(수용 기준 S12).
- **티켓의 포팅 대상 3종 이름이 스테일**: `gallery`·`current-region`은 웹에 존재하지 않는 파일이다(MSG-327이 폐기). 위 parity 계획에서 실제 `RN 재사용 대상` 표기 파일로 재정의했으나, 사용자가 다른 파일을 의도했다면 조정 필요.
- **`apps/mobile` 테스트 인프라 제약**: `vitest.config.ts`가 "순수 모델(RN import 없는 로직)로 한정"이라 명시하고 RNTL·jest-expo를 도입하지 않는다(MSG-292 확정 4). 따라서 **UI 컴포넌트 렌더 테스트가 불가능**하고, 화면 기준 S1~S13은 전부 실기/에뮬레이터 수동 검증에 의존한다. 로직 기준을 순수 함수로 최대한 밀어내는 설계가 그 보상이다.
- **`resolveMapCenter()`의 권한 요청 부수 효과**: 도감 진입 시 위치 권한 팝업이 뜰 수 있다. 통상 홈(`/home`)에서 이미 요청됐지만, 도감을 첫 화면으로 딥링크 진입하면 도감에서 처음 뜬다. 권한 거부 시 서면 좌표 폴백이라 화면은 깨지지 않는다(총함수 계약).
- **`entities/dex` 신설이 웹 생성 타입에 결합**: `apps/mobile/src/entities/dex/model/dex.ts`가 `apps/web/src/shared/api/generated/types.gen.ts`를 type-only import한다. 크로스 앱 경로가 `shared/api/sdk.ts`·`query-options.ts` 2파일에 갇혀 있다는 MSG-419 원칙과 어긋난다 → **`sdk.ts` 배럴(`export * from generated`)을 경유해 타입을 가져온다**(`import type { CollectionSummaryResponseDto } from "../../../shared/api/sdk"`).
- **NativeWind 클래스 승자 규칙**: 공통 컴포넌트 기본값(`ProgressBar`의 `h-1.5`, `StatTile`의 내부 클래스)을 `className`으로 덮으려면 **문자열 순서가 아니라 생성 스타일시트 순서**가 승자를 정한다(MSG-421 실측). `h-2`가 `h-1.5`를 못 이기면 `!h-2` 수식자를 쓴다.
- **디자인 토큰 공백**: Figma raw hex 중 `#ebebef`(진행 트랙)·`#ececef`(rule)·`#e5e7eb`(비활성 pill 보더)에 대응 토큰이 없다. 전부 `border`(#E0E0E0) 계열로 환산한다 — 임의값(`bg-[#ebebef]`) 금지 규칙 준수. 미세한 색 차이는 결함이 아니다.

### Figma 오탐 방지 (page-verifier 판정 기준)

1. **플레이스홀더 문자열 불일치는 결함이 아니다** — `부산진구 52%`·`6개/4개/12일`·`서면/양정/부천/광안리/전포/초량`·`서면 A-02`·`1:24`·`#4`·`어제 수집`·`격자 6개 · 영상 11개`는 전부 디자인 샘플이다. 특히 **`부천`은 경기도 시명**이라 MVP 지역 정본(부산) 위반 — 실데이터로만 채운다.
2. **통계 타일 타이포가 Figma보다 크다** — Figma 값 16px SemiBold / 라벨 11px Regular이지만 `StatTile`은 `text-fm-display`(20/600) / `text-fm-label`(12/500)이다. MSG-420이 "토큰에 18px 단이 없음 — 임의값 금지"로 확정한 값이고, 공통 컴포넌트 재사용이 규칙 1·3보다 우선한다. **차이는 의도**.
3. **섹션 헤더 타이포** — Figma "최근 수집한 격자" 16px SemiBold에 대응 토큰이 없어 `text-fm-title`(15/600)을 쓴다. 1px 차이는 결함 아님.
4. **진행 바 트랙 색·높이** — Figma `#ebebef`/8px → 토큰 `bg-border`(#E0E0E0)/`h-2`. 색 차이는 토큰 규칙 준수의 결과.
5. **빈 상태·로딩·실패·`regionUnresolved` 화면은 Figma에 레이어가 없다** — 프레임은 기본 상태만 그려져 있다. 이 4개 분기가 시안과 다르다고 결함 판정하지 말 것(수용 기준 S10·S11·S12가 정본).

7. **"지도 탭"에 지도가 없다** — 프레임명은 지도 탭이지만 시안에 지도 렌더 영역이 없고, 티켓 제외 범위이기도 하다. 지도 미표시는 결함 아님(추정 A5).
8. **갤러리 헤더에 뒤로가기 `‹`가 시안보다 추가된다** — Figma 갤러리 프레임의 `AppHeader`는 좌측이 비어 있으나 요구 ⑧이 복귀 수단을 요구한다. 추가는 의도(Q3 결정에 종속).
9. **활성 탭 pill에 체크 아이콘이 없다** — `ui-native` `Chip`을 쓰지 않고 로컬 `DexTabBar`를 만든 결과이며 Figma와 **일치**한다. 종전 화면(`Chip` 사용)과 달라 보이는 것이 의도.
10. **NEW 배지가 썸네일 위가 아니라 메타 줄 우측에 있다** — Figma 실측 그대로다(웹은 같은 위치). 오버레이가 아닌 것이 정답.
11. **영상 카드 재생 원이 흰 원 + 파란 삼각** — Figma는 파란 원 + 흰 삼각이지만 앱 카드 관례를 우선한다(Q2 결정에 종속, MSG-420 주석에 이월 근거 기재).
12. **폰트가 Inter가 아니다** — Figma 텍스트는 전부 Inter로 지정돼 있으나 한글 실렌더는 시스템 폰트다. 자간·행간 미세 차이는 결함 아님.

## 3. 검토한 대안과 기각 이유

① **갤러리 2단 쿼리를 셸이 소유**(스펙 문면) → 기각. `selected === null` 구간 내내 비활성 쿼리를 들게 되고, 같은 스펙이 지시한 "동 변경 시 `key` 리마운트로 상태 초기화" 계약과 충돌한다. `region-gallery-view`가 소유하는 편이 셸을 갤러리 상태 5종으로부터 격리해 **MSG-430 무수정 목표를 오히려 강화**한다(웹 `GalleryTabBody`도 동일 배치). 검증에서 확장 계약 유지 확인.

② **웹 원본을 문자 단위로 복제**(`.at(-1)`·`toSorted`) → 기각. Hermes 0.17(RN 0.86)에 `toSorted` 미구현이라 Node 테스트만 통과하고 실기에서 크래시한다(선례 `sort-grid-videos.ts`). 인덱스 접근·스프레드 sort로 치환했고 결과 동등성은 parity가 **값으로** 고정하므로 구현체 차이가 드리프트 감지를 무력화하지 않는다.

③ **`formatBadgeCount`를 격자 타일에도 재사용**(스펙 표 문면) → 기각. Figma 타일 3칸이 `6개/4개/12일`로 두 형식인데 스펙 표엔 개수 포맷터 1개뿐이고 스트릭 포맷터가 누락됐다. 이름이 용도를 속이므로 `formatCountTile`·`formatStreakTile` 2종으로 역할 명명.

④ **웹 `GallerySelection` 대응 타입 신설** → 기각. `RecentRegion`이 이미 `regionName`·`sampleGridId`를 둘 다 갖는다. 웹은 지도 오버레이 격자 클릭이라는 두 번째 진입점 때문에 별도 타입이 필요했지만, 모바일은 진입점이 동 행 하나뿐이다(A5로 지도 영역 자체가 없음).

⑤ **`mock-profile.test.ts`의 스트릭 정합 케이스를 리터럴 `12`로 치환** → 기각. `expect(MOCK_PROFILE.streakDays).toBe(12)`라는 동어반복만 남는다(테스트 템플릿이 금지하는 형태). 앵커 `MOCK_COLLECTION_SUMMARY`가 이 티켓의 필수 삭제 대상이고 도감 스트릭이 실 API로 바뀌어 "두 mock이 같은 사용자를 말한다"는 불변식의 한쪽이 소멸했다. 같은 파일의 부산 가드·ISO 가드는 **보존**돼 커버리지 손실이 없다.

⑥ **중복 게이트에서 포팅분을 공통 추출** → 기각. 웹을 런타임 import하면 웹 리팩터가 모바일 번들에 직결된다(envelope·api-error·consent-gate가 세운 "복제 + parity 테스트" 관례). 의도 중복으로 `nose.baseline.json`에 등재.

⑦ **탭 상태를 expo-router 세그먼트(`/dex/:tab`)로** → 기각(추정 A2). 웹은 URL이 정본이지만 모바일에 대응 라우트가 없고, 세그먼트를 추가하면 MSG-430과 소유권이 충돌한다. 화면 로컬 `useState` 유지.

⑧ **X 감춤을 zustand 스토어로**(웹 `recent-removal-store` 대응) → 기각(추정 A4). `apps/mobile`에 zustand 의존성이 없다. 화면 로컬 `useState<string[]>`이라 **화면 이탈 시 리셋**된다(웹은 탭 이동 후에도 유지) — S5는 "누르면 그 행만 사라진다"까지만 요구해 기준 충족에 영향 없음.

## 4. 사용자 승인 결정 5건 (스펙 "승인 기록" 절 참조)

## 6. 후속 권장 (결함 아님 — 지라 환류 대상)

1. **뱃지 탭 `mt-md` 이중 여백** — 새 셸의 `gap-md` 위에 겹쳐 상단 여백이 지도 탭보다 넓다. Q1이 "무수정 존치"라 이번 범위 밖이고, 본문을 교체할 **MSG-430**이 정리할 자리다.
2. **삭제 모듈을 가리키는 스테일 주석 2건** — `features/dex/model/mock-badges.test.ts:4`, `entities/profile/model/profile.ts:14`. 문자열이라 컴파일·테스트 영향 없음. 뱃지/프로필 실 API 전환 티켓에서 함께 정리.
3. **재시도 시 탐험률 진행 바 미갱신** — 셸 재시도가 `summary`·`grids`만 refetch하고 `by-point`를 건드리지 않아, 네트워크 복구 후 목록은 돌아오지만 진행 바는 화면 재진입까지 비어 있다. `dex-screen` JSDoc이 명시한 의도된 부분 실패 동작이고 S11 문면도 충족하나, `regionStat.refetch()` 1줄 동반이 UX 개선안.
4. **X 유효 터치 ≈38dp** — Figma 실측 14px 아이콘 + `hitSlop={12}`. 44dp 권고 미달이지만 MSG-420 환류 관례를 승계한 값. 맞추려면 `hitSlop={15}`.
5. **`DexErrorState` 승격 후보** — MSG-430·431이 쓰면 3번째 사용처가 되어 `ui-native` 승격 판단 대상.
6. **환경 — 고아 metro 정리** — 삭제된 워크트리 2곳(`sc-levitated-niobium-8530` :8081, `sc-coherent-magnon-b3d4` :8092)의 metro가 살아 있어 dev client가 그쪽 번들을 받아 `ConfigError`를 냈다. 병렬 웨이브 종료 시 metro 종료 누락이 원인 — 다음 세션이 같은 함정에 빠진다.

## 7. codex 리뷰 1회 (커밋 전)

지적 **1건(P2)** — 코드로 타당성 확인 후 반영했다.

> 목록 아래쪽 동을 선택하면 같은 `ScrollView`가 마운트를 유지한 채 본문만 `RegionGalleryView`로 교체돼 **기존 세로 오프셋이 남는다** — 갤러리가 중간부터 열려 헤더와 첫 영상이 가려진다.

실기 검증이 놓친 이유는 S6를 **목록 상단 행**으로 확인했기 때문이다(오프셋 0이면 증상이 나타나지 않는다). 갤러리 복귀·탭 전환도 같은 경로다. 조치는 셸 `ScrollView`에 ref를 달고 `useEffect([selectedRegionName, tab])`에서 `scrollTo({ y: 0, animated: false })` — 세 경로를 한 곳에서 처리한다. 갤러리 뷰를 별도 `ScrollView`로 분리하는 대안은 셸의 단일 스크롤 컨테이너 구조를 깨 경로마다 스크롤 상태가 갈리므로 기각했다. 뷰 레이어라 회귀 테스트는 작성 불가(5절 WAIVED 사유 동일).

## 8. 게이트 스크립트 정정

드리프트 검사 명령은 `pnpm api:generate`가 **아니라 `pnpm openapi-ts`**다(루트 `package.json`에 `api:generate` 없음). CI 절차는 `pnpm openapi-ts` → `git diff --exit-code -- apps/web/src/shared/api/generated` → `git status --porcelain` 공백 확인. 중복 baseline 갱신에는 별도 스크립트가 없어 `check:duplication`과 같은 인자에 `--write-baseline`을 덧붙인다(`nose baseline` 서브커맨드는 존재하지 않음).
