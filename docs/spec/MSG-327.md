# MSG-327: 개인 도감 API 연동

## 기획 요약

개인 도감(프로필 헤더·요약·최근 수집·갤러리·뱃지)의 mock-dex를 실 API 6종으로 교체하고, 최신 Figma(14599-*)에 맞춰 UI를 개정한다. 핵심 UI 변경 3가지 — ① "최근 수집한 격자"가 격자 단위에서 **동(행정동) 단위** 목록으로, ② 동 클릭 시 그 동의 **격자별 그룹 + 1열 영상 카드** 갤러리로, ③ 뱃지가 민무늬 색 원에서 **실제 메달 아트**(code 매핑)로 바뀐다. 프로필 헤더는 `GET /api/users/me` 실데이터를 쓴다.

**사용자 기확정 해석** (재질문 불필요, 2026-08-14):
1. 최근 수집 묶음 단위 = **행정동(regionName)** — `collections/videos`가 regionCode(행정동)만 받으므로.
2. "전체 지도 N% 탐험" 문구 = **대응 API 없음 → 다른 문구로 교체**(있는 값 기반) + 백엔드 환류.
3. 갤러리 NEW 배지 = **createdAt 기준 최근 24시간 이내**.

## 리스크

- **명세 갭 — CollectionGridResponseDto에 regionCode 부재**: 동 묶음 → `collections/videos?regionCode=` 호출에 코드가 필요해 `regions/stats` regionName 매칭으로 우회한다. 동명이동(다른 시군구의 같은 행정동명)이 있으면 오매칭 가능 — **백엔드 환류 필수**(기준 11이 미매칭 방어를 커버)
