# MSG-561: [모바일] 홈 로그인 게이트 — 앱은 로그인 필수, 비로그인 사용자는 온보딩 뒤 로그인 화면으로

> 원문: `_workspace/MSG-561/00_ticket.md` (atlassian MCP 조회, 2026-09-03) · 환류 출처: `docs/spec/MSG-560.md` §5 Q3·R4 · 뒤집는 설계: `docs/spec/MSG-421.md` "라우팅" 절(온보딩 완료 → `/home`)
> **수정 범위: `apps/mobile`만.** `apps/web`·`packages/**` 0줄. `features/event`·`features/upload`·`map-home/ui/grid-map.tsx`·`map-home-screen.tsx` 0줄.
> 원칙(사용자 메모리): 웹 코드·서버 계약으로 확정할 수 있는 결정은 되묻지 않는다. 앱은 로그인 필수 — 익명 사용자 분기를 만들지 않는다. Figma 링크 없음(티켓 [참고]) — 신규 UI 0이라 대조 대상도 없다.

## 기획 요약

온보딩 "시작하기"가 로그인 없이 지도 홈으로 들어가는 현재 코드(`app/index.tsx` — 온보딩 완료만 보고 `/home` Redirect)를 제품 규칙 "앱은 로그인 필수"에 맞춘다. 온보딩을 끝내면(시작하기·건너뛰기 모두) 로그인 화면으로 가고, 로그인해야 홈이 보인다. 재실행 시 세션이 있으면 스플래시 → 홈 직행, 없으면 로그인. 딥링크·업로드 이어가기·푸시 탭으로 무인증 진입해도 로그인 화면으로 막는다. 로그아웃·재발급 실패 → 로그인(기존 `goToLogin` 배선 유지), 동의 게이트(MSG-422)는 로그인 게이트 뒤에서 기존대로. 로그인 화면·카카오 로그인·라우트별 게이트·익명 발사 쿼리는 손대지 않는다.
