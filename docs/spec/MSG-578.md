# MSG-578: [모바일] 검색 실연동 — 인기 검색어·장소 검색·격자 검색 (웹 MSG-328·412 이식)

## 기획 요약
앱 검색 화면(`/search`)이 MSG-297 목데이터 상태(구 목록 로컬 매칭, 결과 화면 없음)에 멈춰 있다. 웹이 MSG-328(인기 검색어·장소 검색)·MSG-412(격자 검색 "서면 A-14")로 실연동한 것을 앱에 이식한다. 인기 검색어 TOP 10 → 탭 즉시 장소 검색, 입력 300ms 디바운스 장소 검색(Enter·아이콘·인기 검색어는 즉시), zones 세션 1회 캐시 기반 로컬 역파싱 격자/구역 섹션, 결과 탭 시 홈 복귀 + 지도 이동(격자는 줌 보장 + 테두리 하이라이트, 구역은 사각형 fitBounds). 기존 화면은 최근 검색 유지·전체 지역을 `useExploreRegionsQuery`로 교체·최근 방문 섹션 제거·placeholder "장소, 격자 검색". 서버·웹·packages 무수정.
