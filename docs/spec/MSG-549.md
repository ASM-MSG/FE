# MSG-549: 내 신청 목록 + 심사 결과 상세 3상태(심사 중 · 승인 · 반려)

## 기획 요약

운영자 콘솔 스텁 2장을 실구현으로 교체한다. `/org/submissions`는 `GET /api/org/event-submissions/my`로 내 신청 목록(행사명·기간·상태 뱃지 + 상태 필터)을 보여주고, 행 클릭 시 `/org/submissions/{id}` 상세로 이동한다. 상세는 `GET /api/org/event-submissions/{submissionId}` 하나로 상태별 3분기(심사 중 안내 / 승인 안내 / 반려 항목 라벨+자유 서술 사유)를 렌더하고, 기본 정보·위치 영역 요약(제출본)·신청 이력(제출/반려/재제출 시각)을 함께 보여준다. 반려 상세의 "재신청"은 `/org/submissions/{id}/edit`(MSG-550, 현재 위저드 새 등록 모드로 착지) 라우팅만 한다.
