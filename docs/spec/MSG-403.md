# MSG-403: 랜더링 오류 수정 (칩 표시 범위·갱신 시점 + 미션 API 마이그레이션)

## 기획 요약

MSG-395로 붙인 상단 칩 4종이 **표시 범위**(칩을 켜도 내 점령 격자가 같이 뜨고, 줌아웃하면
칩 데이터가 사라짐)와 **갱신 시점**(지도를 움직일 때마다 재조회·헤더 변경)에서 기획과
어긋난다. 여기에 좌측 패널 접힘 시 칩까지 사라지는 문제와 사이드레일 재클릭 동작 개선을
더해 6건을 잡는다.

동시에 백엔드 미션 API가 개편되어 현재 워킹트리는 컴파일되지 않는다 —
`/api/missions/active`가 `type` + bbox 필수 영역 조회가 되었고, 진행도·상세·미션 영상이
서버 API로 열렸다. "영역을 불러올 때만 갱신"이 3번과 같은 모델이라 함께 처리한다.

## 추정 및 질문

1. **칩을 켜는 순간은 자동으로 1회 확정한다** — 2번(줌아웃하며 데이터 표시)과 3번(버튼으로만
   갱신)이 충돌하는 지점이다. 칩 활성화는 명시적 사용자 행동이므로 그때 줌 이동 후의 화면
   영역을 자동 확정하고, **이후의 이동·줌은 버튼으로만** 갱신하는 것으로 해석했다.
   (자동 확정을 빼면 500m/1km로 넓힌 화면에 좁은 영역 데이터만 뜬다)
2. **확정 영역은 점령 격자·핫구역 조회에도 적용한다** — "현재 위치가 바뀔 때마다 격자를
   렌더링해오는 것"을 막아 달라는 요구를 지도 데이터 전반으로 읽었다. 결과적으로 칩이 없는
   기본 홈에서도 지도를 이동하면 점령 격자가 즉시 따라오지 않고, 버튼을 눌러야 갱신된다
3. **접힘 시 칩 바는 지도 좌상단(패널 자리)으로 이동**한다 — Figma 노드가 없어 기존 여백
   관례를 따랐다
4. **초기 상태 정의** — 홈: 칩 해제 + 상세·미니 패널 닫힘 + 격자 리스트 모드 / 도감: `/dex`
   지도 탭 + 동 갤러리 밖 / 프로필: 모달 없음
5. **진행도 표시 문구는 유지**한다 — 값의 출처만 서버로 바꾸고 `내 진행 n/N칸`·`n/N곳 방문`
   문구와 배지 규칙은 MSG-395 그대로 둔다

## 리스크

- **bbox 0.5도 상한**: 미션 조회는 span 0.5도 초과 시 400(`developCode 12401`)이다. 경로추천
  1km 줌에서 뷰포트가 상한에 근접할 수 있어, 초과 시 명세 지시대로 "확대 안내"로 떨어뜨려야
  한다. 실측으로 임계를 확인하고 처리 경로를 만든다
- **THEME 미션 누락 가능성**: 요청 `type` 문서값은 3종인데 응답 enum은 6종이다. `type=EVENT`에
  THEME가 섞이는지 로그인 세션으로 실측한다(익명 401). 섞이지 않고 `type=THEME`도 거절되면
  축제 목록에서 THEME 미션이 빠지므로 그 사실을 작업 로그에 남긴다
- **문서-코드 어긋남**: `use-active-missions-query` 주석의 "미션은 공개 정보" 전제가 실측
  (익명 401)과 다르다 — 주석도 함께 고친다
- **회귀 범위**: 확정 영역 전환은 홈뿐 아니라 셸 상시 층(도감·프로필 화면에서도 보이는 점령
  격자)에 영향을 준다. 도감·프로필 진입 시 지도 표시가 죽지 않는지 확인 대상에 포함한다
- **Figma 오탐 방지**: 이번 티켓에는 Figma 노드가 지정되지 않았다. 접힘 시 칩 바 위치(추정 3),
  칩 화면의 `장소 불러오기` 버튼 배치는 **기존 컴포넌트·여백 관례를 따른 신규 배치**이므로
  Figma 대조에서 불일치로 판정하지 않는다

- **확인불가**: `type=EVENT` 응답에 `THEME` 미션이 섞이는지 미확인(응답 본문 접근 수단 없음).
  섞이지 않으면 THEME 미션이 축제 목록에서 조용히 빠진다 — 지라 코멘트로 환류.
- **범위 밖(스펙 합의)**: 위치 동의(`PUT /api/users/me/location-consent`)는 타입 정합만,
  미션 영상 무한 스크롤은 첫 페이지만.

### codex 리뷰 반영 (커밋 전 1회)

- **P1**: 전체 보기의 지역 선택이 무관한 뷰포트를 함께 확정해 AC 11을 우회하던 문제 →

  행정동 도착까지 대기, 확정을 활성화당 1회(줌 도달 후)로 단일화.

- 코스 연결선은 `coursePath(line, spots)`가 만든다 — 서버 라인(`shape.line`)이 있으면 그대로,
