## 추정 및 질문 (사용자 승인 대상)

- **Q1 — 건너뛰기 삭제 (추정·결론: 삭제).** 시안 3장 모두 TopBar가 비어 있고 3장 프레임은 컨테이너만 남아 자식이 0이다 — 디자이너가 의도적으로 뺀 것으로 읽힌다. 기능적으로도 건너뛰기와 시작하기는 MSG-561 D4 이후 **같은 경로**(`setCompleted(true)` → 판정)라 사라져도 도달 불가능한 상태가 생기지 않는다(로그인은 3장 "시작하기"로 똑같이 간다). 결과: `isSkipVisible`·`onSkip`·`handleSkip` 삭제, `index.tsx` 1줄 삭제, MSG-421 Q1(건너뛰기도 완료 저장)은 **소멸**. 유지를 원하면 TopBar 우상단에 기존 "건너뛰기" `Pressable`을 그대로 두고(시안과 의도적 차이 → 오탐 방지 등재) `isSkipVisible`을 남긴다.
  - Q1-b: `index.tsx`를 문자 그대로 무수정으로 두고 싶으면 `onSkip?`을 optional 미사용 prop으로 남긴다 — 죽은 prop이라 권장하지 않음.
- **Q2 — 일러 색상 처리 (추정·기본안: 정확 토큰 3종만 보간, 나머지 hex 유지).** 대안 ①: 파랑 4단을 `${primary}` + `fill-opacity`(0.065/0.19/0.34/0.6)로 표현 — 흰 배경 위에서는 Δ≤3이지만 격자 칸이 원형 배경(`#EFF5FB`) 위에 얹혀 실제 합성색이 Δ6까지 벌어지고, 3장 빨강은 이 방식으로 못 만든다. 대안 ②: 원시 토큰 8종 선등록(`illust-blue-50/100/200/300`, `illust-red-500/200/100`, `illust-line`) — `theme-*`·`grass-*` "근사 금지" 선례와 정합하지만 1회용 일러 색 8개가 `design-tokens`에 들어간다. 기본안은 뱃지 아트 선례와 같고 diff가 가장 짧다.
- **Q3 — 3장 빨강 `#F5533D` (기본안: 시안값 유지).** 핫구역 의미상 `theme-hot`(`#FF3B30`)로 치환하는 대안이 있다 — 지도 홈 핫구역 색과 일러가 같아진다는 장점, 시안과 색이 달라진다는 단점. 기본안은 시안 정확 일치(Q2 기본안의 귀결).
