# MSG-603: [모바일] 행사 알림 구독 토글 (시안 없음 — FE 설계)

## 기획 요약
행사 개요 시트(기간·시청 인원 행 아래)에 `🔔 행사 알림 / 시작할 때와 일정이 바뀌면 알려드려요` + Switch 한 줄. 예정·진행 중 회차에만 보이고 종료 회차에는 없다. 낙관 반영, 실패 시 롤백 + 인라인 안내.

## 코드베이스 현황
- 생성 SDK `updateSubscriptionMutation`(PUT, body `{enabled}`, 응답 `{enabled}` 노출값) · 상세 `EventOccurrenceDetailResponseDto.notificationOn` 이미 존재. 재생성 불필요.
- 개요 시트 `event-overview-sheet-content.tsx`는 `use-event-home.ts`의 `EventOverview`만 읽는 얇은 뷰 — 재료를 overview에 더한다.
- 종료 판정 `event-status.isArchivedEventStatus` 재사용. 낙관 선례 `event-video-mutations.ts`.
- 웹에도 토글 없음 — 웹은 별도.

## 디자인 결정
- 위치: 기간·시청 인원 행 바로 아래(헤더는 ‹·제목·배지·✕로 꽉 참). 카드형(surface-soft) 한 줄, 좌 Bell(primary) + 라벨·캡션, 우 Switch.
- 종료 회차는 행 자체를 숨긴다(비활성 토글보다 단순, 서버도 ON 거부).
- EVENT 카테고리 OFF 안내는 범위 밖(티켓 제외).

## 작업 로그
- **설계**: 개요 시트 기간 행 아래 카드 한 줄(🔔 + "행사 알림 / 시작할 때와 일정이 바뀌면 알려드려요" + Switch). 종료 회차는 행 자체를 숨긴다(서버 ON 409, 노출값 항상 false). 표시값은 상세 캐시 `notificationOn` — 낙관 기록이 곧 화면.
- **mutation**: 성공 응답 `enabled`(노출 파생값)를 기록해 요청 사이 회차가 종료된 경우 낙관 true를 서버 false가 덮는다. 실패는 직전 값 복원. 토글 하나뿐이라 겹침은 같은 키 덮어쓰기로 수렴(알림함 MSG-602의 겹침 문제와 달리 항목이 하나).
- **검증**: vitest 6건 + 게이트 통과. Android 실기 부산국제영화제(D-13) ON → 콜드 스타트 후 ON 유지, 종료 행사(LoL)는 행 없음.
- **검토한 대안**: ① 헤더 우측 벨 아이콘 버튼 — 헤더가 ‹·제목·배지·✕로 꽉 차 기각. ② 종료 회차에 비활성 토글 표시 — 켤 수 없는 토글은 혼란만 주므로 숨김. ③ EVENT 카테고리 OFF 안내 — 범위 밖(티켓 제외).
- **codex 리뷰(P2 1건) 반영**: 재마운트로 겹친 요청의 늦은 응답·롤백이 최신값을 덮는 문제 → 회차별 요청 순번 가드 + `useIsMutating` 진행 중 표시. 순서 역전 테스트 2건 추가.
- **PR #159 리뷰(🟡1·🟢1) 반영**: `isError`도 `useMutationState`로 재마운트 내성(실패 안내 누락 경로 해소), `latestSeq` 정리. 재마운트 후 실패 안내는 RN 렌더 테스트가 없어 실기·로직 테스트 밖 — 훅 파생이 `statuses.at(-1) === "error"` 한 줄이라 코드 리뷰로 갈음.
