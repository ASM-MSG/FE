# MSG-475: 줌아웃 클러스터 마커 리디자인 — Figma 신규 마커 적용 + 칩별 테마 색 분기 + 핫구역 행정 단위 집계 마커 연동

## 기획 요약

줌아웃(축척 250m 이상) 시 뜨는 행정 단위 집계 마커(도감 점령·축제·팝업)를 Figma `15221-20097`
말풍선 디자인으로 교체한다 — 도감 마커가 기본형이고, 축제·팝업 칩 활성 중에는 같은 형태에 채움색만
칩 테마 토큰으로 갈린다(MSG-451 ① 규칙 유지, 새 토큰 없음). 핫구역 칩은 지금까지 줌아웃해도 100m
격자 낱개(전국 상위 50)로 남아 점으로 뭉개졌는데, 서버 집계 `GET /api/hotzones/aggregation`(BE
MSG-466)을 미션 집계와 같은 게이트·클램프로 연동해 행정 단위 마커(숫자 = 핫 격자 수, 색 = 핫구역
테마)로 묶는다. 겹침 병합·이름 승계·미판정 버킷·드릴다운 줌은 기존 그대로이고, 모바일 포팅본은
파생 로직 parity만 유지한다(RN 렌더 교체는 범위 밖).

## 추정 및 질문 (승인 전 원문 — 위 결정이 정본)

**사용자 확인 필요:**

1. **노드 컨텍스트** — `15221:20097`은 탐색 보드 "mock-3 ③ 인스타그램 맵·스냅맵형 — 원형 썸네일 핀" 안에서 `cover-old` 흰 원에 **덮여 있는** 요소다(보드 스크린샷에는 원형 썸네일 핀만 보임).
   티켓이 이 말풍선을 명시했으므로 **말풍선을 정본으로** 스펙을 썼다. 원형 썸네일 핀(③ 안)이 의도였다면 스펙을 다시 써야 한다(썸네일 소스가 집계 응답에 없어 서버 계약부터 달라진다)
2. **도감 기본형 채움색 = `bg-secondary`(`#0071E3`)** — 노드 값과 정확히 일치하는 토큰이다. 현 마커는 `bg-primary`(`#0066CC`)였고, 형제 노드 "cluster-bubble/default"는 진회색(navy-900 92%)이다.
   variant 이름상 default(진회색)가 휴지 상태, selected(파랑)가 선택 상태로도 읽히는데, 티켓이 20097을 "기본형"으로 지정했으므로 **파랑 단일 상태**로 간다(호버/선택 상태 전환·진회색 변형은 미구현). 대안: 브랜드 일관성을 위해 `bg-primary` 유지(1단계 어두운 파랑)
3. **`gridIds` 교집합 좁힘 — 이번 범위에서 미구현 권고, 결정 필요.** 티켓은 "핫구역 묶음 클릭은 줌인 후 gridIds 교집합으로 좁힘(MSG-466 확정)"이라 쓰였지만, 현 구조에서 효과가 거의 없다:
   ① 시/구 마커 클릭은 4km/500m 단(여전히 집계 구간)에 내려 개별 조회 자체가 없고, DONG 마커 클릭만 격자 줌에 닿는다 ② 격자 줌의 핫구역 패널·셀은 이미 **확정 행정동(regionName)** 으로 걸러지는데, 서버가 "집계와 개별 조회의 판정 집합이 같다"고 명시했으므로 DONG 마커의 `gridIds`와 그 동의 개별 결과는 원리상 같은 집합이다(차이는 미판정 null 버킷뿐).
   MSG-451이 같은 이유로 `missionIds` 좁힘을 후속으로 미룬 선례가 있다. **권고: AC 17 제외, `gridIds` 미소비(AC 10)** — 구현하기로 하면 포커스 스토어 + 교집합 순수 함수 + "언제 풀리는가"(칩 전환·다음 클릭·확정 지역 변경?) 규칙을 추가로 정해야 한다
4. **타이포 토큰 근사** — Figma 11/15 Medium·17/21 Bold와 정확히 맞는 `text-fm-*` 토큰이 없다. `text-fm-label`(12/15 500)·`text-fm-heading`(16/20 500)+`font-bold`로 각 1px 차이 근사한다.
   대안: `typography`에 마커 전용 2종 신설(티켓의 "새 토큰 없음"은 색 토큰 문맥이라 위배는 아니지만, 사용처 1곳 토큰은 관례상 보류). 임의값(`text-[17px]`)은 DESIGN_SYSTEM 감사 대상이라 쓰지 않는다
5. **그림자는 `shadow-raised` 유지**(Figma `0 2px 6px .25`보다 퍼짐이 크고 옅다) — 토큰 신설 대신 최근접 사용
6. **병합 임계 `MARKER_MERGE_PX`(68/80/92) 불변** — 티켓 ④ "병합 규칙 기존 그대로" + 모바일 parity 테스트가 리터럴로 고정 + RN 렌더가 원 지름으로 소비. 말풍선(약 61×49, 폭 가변)과는 근거가 어긋나므로 주석에만 명기하고 재보정은 RN 렌더 교체 티켓과 함께 한다
7. **핫 집계 bbox는 뷰포트**(도감·미션 집계와 동일한 확정 영역 정본 예외 — 저줌엔 "장소 불러오기"가 없어 확정 영역으로는 갱신 수단이 없다). 핫구역 **개별** 조회는 종전대로 확정 영역
8. **핫 칩 저줌에서 좌측 패널은 무변경** — 확정 행정동의 동 요약을 계속 보여준다(마커는 지도 층만 바꾼다). 핫 셀 게이트에는 미션과 달리 상세 예외가 없다(핫구역엔 상세 대상이 없음)
9. **핫 집계 실패는 조용히 빈 마커**(도감·미션 집계와 동일 — 지도 위 오류 UI 없음)

### 검토한 대안 (기각 이유)

- **`api:generate` 재실행** — 기각. 티켓 [참고]의 "로컬 스냅샷에 hotzones/aggregation 없음"이 스테일이었다: `getHotZoneAggregates`·`getHotZoneAggregatesOptions`·`HotZoneRegionAggregateResponseDto`가 MSG-445 커밋(`4639232`)의 스냅샷 갱신에 이미 딸려 와 있었다. 재생성은 이 티켓과 무관한 diff만 만들고 병렬 MSG-474와의 충돌 창을 연다. **착수 전 생성물 실물 확인이 재생성 계획을 지웠다.**
- **`gridIds` 교집합 좁힘 구현** — 기각(사용자 승인). 시/구 마커 클릭은 4km/500m 단(여전히 집계 구간)에 내려 개별 조회 자체가 없고, DONG 마커 클릭만 격자 줌에 닿는데 그 화면의 핫구역 패널·셀은 이미 **확정 행정동**으로 걸러진다. 서버가 "집계와 개별 조회의 판정 집합이 같다"고 명시했으므로 교집합의 효과는 미판정(null) 버킷뿐. 구현하면 포커스 스토어 + "언제 풀리는가" 규칙이 따라붙는다. MSG-451이 `missionIds`를 같은 이유로 후속으로 미룬 선례.
- **채움 `bg-primary` 유지** — 기각. Figma 노드 실측 `#0071E3`이 `bg-secondary`와 **정확히 일치**한다(현행 `bg-primary`는 `#0066CC`). 브랜드 일관성보다 디자인 정본 일치를 택했다.
- **마커 전용 타이포 토큰 신설**(11/15 Medium · 17/21 Bold) — 기각. 사용처 1곳 토큰은 관례상 보류하고 `text-fm-label`(12/15)·`text-fm-heading`(16/20)+`font-bold`로 각 1px 근사했다. 임의값(`text-[17px]`)은 디자인 시스템 감사 대상이라 배제.
- **그림자 토큰 신설**(Figma `0 2px 6px .25`) — 기각. `shadow-raised` 최근접 사용.
- **`MARKER_MERGE_PX` 재보정** — 보류. 말풍선(약 61×49, 폭 가변)과 원 지름 기반 임계(68/80/92)는 근거가 어긋나지만, 모바일 parity 테스트가 리터럴로 고정하고 RN 렌더가 이 값을 원 지름으로 소비한다. RN 렌더 교체 티켓과 함께 재보정한다(주석에 근거 명기).
- **집계 훅 3형제 공통 헬퍼 추출**(nose 제안) — 기각. 도감·미션·핫 훅은 생성 옵션 함수·쿼리 파라미터 형태·게이트 조건·placeholder 비교·마커 팩토리가 **9개 지점에서 갈린다**(nose 자신의 파라미터 판정). MSG-476이 같은 근거로 추출을 기각한 선례를 따라 baseline 등재로 처리했다.

### WAIVED · 확인불가

- **확인불가 1건 — AC 2(미판정 버킷)**: `regionCode`/`name`이 null인 항목이 실데이터에 없다(전국 SIDO 범위 직접 프로브 결과 부산 1건뿐). 파생 로직은 단위 테스트(`hot-DONG-unassigned-0` 키·name null·count 유지)로, 렌더는 도감 병합 마커와 공유하는 기존 `name !== null` 분기로 대체 확인했다. 데이터가 쌓이면 자연 관찰된다.
- **AC 14 일부 대체 확인**: 비로그인 상태의 "칩 없음 → 집계 마커 없음"은 브라우저로 안 봤다(카카오 재로그인 불가로 로그아웃 회피). `use-grid-aggregation-query`의 기존 로그인 게이트 테스트 + `MapShell` 분기 코드로 대체.
- **SIDO(16km) 말풍선·다건 병합의 브라우저 관찰 표본 없음** — 실데이터가 부산 1건이라. 단위 테스트가 커버.
- **색 대비(참고, 결함 아님)**: 흰 글자 대비가 hot 3.6:1 · popup 2.2:1 · 지역명줄(백 85%) 4.1:1로 WCAG 4.5:1 미달. MSG-451 미션 마커부터 승계된 테마 토큰 규칙이자 Figma 정본 값이라 이 티켓의 결함으로 잡지 않았다. 지역명줄을 100% 백으로 올리는 것만으로도 개선 여지가 있어 디자인 후속 논의 거리로 남긴다.
- **nose baseline 등재 시 무관 흡수 되돌림**: `--write-baseline`이 develop에도 존재하던 hidden 패밀리 1건(`profile-edit-modal.smoke.test.tsx` ↔ `test/envelope-response.ts`)까지 흡수해 **손으로 제거**했다(MSG-476의 "무관 흡수는 되돌린다" 교훈). 최종 등재는 이번 티켓 파일이 구성원인 패밀리만 — 417 → 425(신규 9 + 재키잉 9 − 제거 1).
